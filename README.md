# Chocolate Sales Analysis – Excel Dashboard

## Project Overview
This project analyzes chocolate sales data using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Dashboard Design

## Project Activities
- Cleaned and prepared the sales dataset.
- Analyzed total sales and profit.
- Compared country-wise and product-wise performance.
- Analyzed monthly sales trends.
- Created an interactive dashboard using Pivot Tables and Pivot Charts.

 Key Insights
- Identified top-performing products.
- Compared sales across countries.
- Analyzed monthly sales performance.
- Evaluated profit trends.
